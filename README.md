# AURA DAM

A beautiful, session-based web application featuring a modern glassmorphism UI. This project demonstrates a full-stack integration using a Spring Boot backend and a dynamic frontend.

## 🚀 Features

*   **User Authentication:** Secure user registration and login system.
*   **Session Management:** Protected routes with a security script that automatically redirects unauthorized users to the `login.html` page.
*   **Modern UI/UX:** Stunning frontend design utilizing a glassmorphism aesthetic for a premium look and feel.
*   **RESTful API:** Clean backend architecture with a `User` entity, `UserRepository`, and `AuthController`.

## 🛠️ Technologies Used

### Frontend
*   HTML5
*   CSS3 (Glassmorphism styling)
*   Vanilla JavaScript

### Backend
*   Java
*   Spring Boot
*   Maven

## ⚙️ Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites
*   Java Development Kit (JDK) installed on your system.
*   Maven installed (or use the provided Maven wrapper).
*   Git installed.

### Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/arpitanibedita/demo.git](https://github.com/arpitanibedita/demo.git)
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd demo
    ```

3.  **Run the Spring Boot application:**
    Open your terminal in VS Code and execute:
    ```bash
    ./mvnw spring-boot:run
    ```

4.  **Access the Application:**
    Open your web browser and navigate to `http://localhost:8080`.
